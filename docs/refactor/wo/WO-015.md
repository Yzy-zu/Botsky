Insumos: plan §3–§7/§8.3; `src/utils/crypto.js`, `src/utils/cleanup.js`, `src/services/cleanup.js`, logger legacy. Implementación CJS + JSDoc + @ts-check, Node20.

APIs entregadas:

- `createLogger({clock,write,secrets?,allowedEvents?,allowedFields?,allowedValues?})` → info/warn/error(event,fields). JSON con timestamp inyectado, evento cerrado, campos técnicos cerrados; strings arbitrarios redacted; valores técnicos cerrados configurados por campo y correlationId UUIDv4 opaco permitido. Copia los vocabularios para que mutaciones del caller no cambien política. No serializa Error.message/stack/cause; solo kind de taxonomía. Profundidad/tamaño acotados, getters omitidos, ciclos tolerados y errores del sink absorbidos. Secrets se enmascaran antes de serializar los valores, manteniendo JSON válido.
- `createMetrics({names,labels?,maxSeries?})` → increment(name,dimensions?,amount?), snapshot(), size(). Vocabularios copiados, labels desconocidos/valores arbitrarios rechazados, series acotadas (default100). Incrementos finitos/no negativos. No etiquetas de texto/identidad de usuario derivadas automáticamente.
- `encrypt(text,masterKey)` / `decrypt(token,masterKey)`: AES256GCM, scrypt32 bytes, salt16 aleatorio e IV12; lee moderno salt:iv:tag:data y legacy iv:tag:data con salt fijo `'salt'`. Mismos parámetros y formato de escritura, sin leer configuración. Corrupción/clave incorrecta falla autenticación. Texto vacío compatible.
- `createMaintenance({fs,clock,tempDir,schoolMediaDir,checkpoint,scheduler,onError?})` → cleanup(...paths), cleanTempDirectory(), cleanSchoolMediaDirectory(), runWalCheckpoint(), runNow(), start(), stop(). FS async inyectado. cleanup explícito best-effort elimina archivos/directorios; limpieza por edad usa unlink y tolera races/directorios como legacy. Umbral estricto >2h temporal / >7d escolar. start explícito registra720000/720000/60000ms y ejecuta ronda inicial; idempotente, stop cancela. Single-flight independiente por limpieza temporal, escolar y checkpoint: llamada inicial/manual/ticker concurrente comparte la misma Promise y una sola ejecución; acciones distintas pueden progresar. La slot se libera al resolver/rechazar. No DB concreta ni conexión al importar.
- `InboundEvent`, `AddressingDecision`, `Decision` JSDoc tal plano; validación isInboundEvent(). `Reply` concretado con partes discriminadas: text{text}; image/audio/video/document/sticker{ref,mime,caption?}; reaction{emoji,messageId}; poll{name,options}. isReply valida variantes; replyTo/ephemeralHint opcionales. La concreción es detalle de payload autorizado en execution-notes; revisar ports cuando se integren adapters.
- `AppError(kind,{cause?})` / `toUserFeedback(error)` → kind,message,nextStep,retryable. Taxonomía completa §8.3; feedback español sin error/cause crudo. Identidades/secrets nunca se incluyen en mensajes del error seguro.
